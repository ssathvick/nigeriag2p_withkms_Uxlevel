The simulated outcomes are labelled throughout. Operational decisions remain in the official approval process.

## Sandbox implementation

The latest Help release adds field guidance for six household intake controls and improves the selection of guidance for explicit PBMS headings, Registry record sections, and role-specific dashboard routes. The portal now shows guide versions, clarifies role handoffs and demo boundaries, and collapses detailed Data Imports exceptions. The public reader suppresses two generic template lines on the 83 affected guides while the editor and history retain the original text.

The earlier release introduced the Finance case register, handoff and instruction lookup. Its SHA-256 manifest remains available for comparison. The V0.2 manifest records the current Help hashes, the portal tree hashes and the changed source files.
