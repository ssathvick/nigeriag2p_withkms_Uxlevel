## Recreating the demonstration on another installation

Sandbox numeric database IDs in the link above are installation-specific. Create a demo household with the supplied name and reference, configure a separate demo programme to select that exact reference, and create enrolment/disbursement cycles using valid closed registration dates. Wait for the normal worker and verify the beneficiary count and reference. Use the intended staff roles for any subsequent approvals. Do not rename another household or change an existing approved beneficiary snapshot to reproduce the demo.
